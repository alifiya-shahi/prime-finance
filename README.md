# Prime Finance

Prime Finance is a personal finance web application that I worked on to understand how a frontend, backend, and database work together in a real application.

The main idea is to provide users with a place to manage financial information through a simple interface. While working on this project, I focused on the React frontend, backend APIs, database operations, and user authentication.

## Tech Stack

- **React.js + Vite** – Frontend and user interface.
- **Node.js** – Backend runtime.
- **Express.js** – Backend routes and API handling.
- **SQLite** – Database for storing application data.
- **JWT** – Token-based authentication.
- **Git & GitHub** – Version control and project management.

## What I Worked On

- Setting up the frontend and backend.
- Connecting the frontend with backend APIs.
- Working with database operations.
- Implementing user registration and login using JWT.
- Handling user requests through Express routes.
- Organizing the application into separate frontend and backend parts.

## Challenges I Faced and How I Approached Them

### 1. Connecting the Frontend and Backend

One of the things I had to work through was understanding how the React frontend communicates with the Express backend.

I worked on connecting the frontend to the backend APIs so that the application could send requests and receive responses instead of relying only on the UI.

### 2. Database Setup

Working with SQLite helped me understand how application data is stored and retrieved.

I had to pay attention to the database connection and the queries used by the backend. This helped me understand the relationship between API requests and database operations.

### 3. User Authentication

Authentication was another important part of the project. I worked with JWT to understand how a user can log in and how the backend can verify an authentication token when handling protected requests.

### 4. Debugging and Integration

When different parts of an application are developed separately, problems can occur while connecting them.

I learned to check the API requests, backend responses, database operations, and configuration when something did not work as expected. This helped me understand the debugging process in a full-stack application.

## Running the Project Locally

### Prerequisites

- Node.js
- npm
- Git

### Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/alifiya-shahi/prime-finance.git
   ```

2. Open the project folder:

   ```bash
   cd prime-finance
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Check the `package.json` file for the available scripts and instructions for starting the frontend and backend.

5. Configure any required environment variables before running the application.

**Note:** The exact startup commands depend on how the frontend and backend scripts are configured in the repository.
